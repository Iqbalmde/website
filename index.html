Understanding Physical AI

Physical AI is the intelligence that lets robots perceive, decide and act in the real world. Making it work on a factory floor is less about one breakthrough model and more about a loop with four parts: data, evals, routing and post-training.

Deployment flywheel

– factories seed the loop

– data as a byproduct of real work

– the advantage compounds with every robot

Data.

Robots have far less training data than language models. Ken Goldberg puts the gap at roughly 100,000 years. The most relevant source is deployment itself. Every run on a real task produces observations, actions and outcomes. When logging is built into the robot's normal work, this data arrives as a byproduct, and it reflects the exact objects, lighting and layouts the robot will meet again.

Evals.

Before a model is trusted with a robot, it has to be measured on the real task in the real environment. An eval runs a model on a defined task and records whether it succeeded, and how it failed. Demos hide this. Vision-language-action models that succeed 80–90% of the time on tasks they have seen can fall to 30–60% on tasks they haven't (SAFE, 2025), and a model that leads on average can still lose on a specific skill, such as precision placement. Good evals are per task, per environment, and continuous, because a factory keeps changing.

Routing.

No single model wins every task, so instead of committing to one, a router chooses the model for each moment, based on the task, the robot and the conditions, and switches before a failure. Routing between VLAs has been shown to lift task success by 13.5 points over a single global model (RouterVLA). It also keeps the system open: a new model joins the pool and is used wherever it wins.

Post-training.

Evals and logged runs flow back into the models. Post-training adapts a model to its environment using its own deployment data. Physical Intelligence reported about twice the throughput and roughly half the failures with this approach. The same runs also teach the router which model succeeds where. Then the loop starts again, deploy, route, eval, post-train, and each cycle compounds.

Deployment.

Real work is the best teacher. The gap between the data behind language models and the largest robot dataset is estimated at 100,000 years. Every deployment logs runs that become evaluation and training data, which produce better models and smarter routing. The advantage compounds with each robot we serve.
